# 구현 전에 공식 문서를 읽는다

> **사용 중인 버전이 제공하는 기능을 먼저 확인한다.**

프레임워크에 있는 기능을 모르고 직접 만들면 유지할 코드가 늘어난다.
문서의 예제가 현재 프로젝트 버전에도 맞는지 확인하고 구현을 시작한다.

1. 프로젝트의 의존성 버전을 확인한다.
2. 공식 문서에서 관련 API, 자동 설정, Starter를 찾는다.
3. 기존 프로젝트가 같은 기능을 어떻게 쓰는지 읽는다.
4. 제공되는 기능으로 해결되지 않는 부분만 직접 구현한다.

문서를 읽었다는 말로 검증을 대신하지 않는다. 선택한 방법이 프로젝트에서 동작하는지는 테스트로 확인한다.

# 작업을 검증 가능한 크기로 나눈다

원래 작업 기준은 30분~2시간 안에 끝낼 수 있고, 하나의 책임을 가지며, 테스트할 수 있는 단위다.
시간은 나누는 기준이지 완료를 보장하는 약속이 아니다.

「외부 도구 통합 구현」 대신 다음처럼 나눈다.

- 서버 연결과 초기화 구현
- 응답에서 도구 목록을 읽어 등록
- 실제 연결을 확인하는 통합 테스트
- 등록한 도구 목록이 예상과 같은지 확인하는 테스트

하나를 구현하고 테스트한 뒤 다음으로 넘어간다. 일부 테스트만 실행했다면 그 범위를 밝힌다.
완료 보고 전에는 프로젝트에서 요구하는 전체 테스트를 확인한다.
